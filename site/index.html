How to read this site

Frozen inputs

Reports are composed from a fixed, merged claim set. New evidence creates a new version instead of silently changing the record.

Public map boundary

The build exports only approved, public or coarsened features after their publication time. Withheld and delayed geometry never reaches the browser.

Traceability

Each publication retains report IDs, claim-set hashes, source commits and repository paths so readers can inspect its lineage.

Explicit empty states

No report or map layer is fabricated. When approved material is unavailable, the site states that directly.

War Reporter publishes versioned analytical records, not live operational targeting data.
